Bench Overview Load path Fabric Drunix Fabric-X NeuChain Normalization

Unified Blockchain Benchmark One adapter interface, one load generator, one metrics pipeline — fair throughput and latency across Fabric, Drunix, Fabric-X, and NeuChain.

Normalized workloads make cross-platform comparison possible. Native caveats (state DB, crypto, read semantics) are recorded in every run’s manifest. Start with a platform card, or read how load becomes a ledger write and how fairness is enforced.

Platforms

Hyperledger Fabric

EOV + chaincode. Raft (CFT) or SmartBFT (BFT). Gateway gRPC → kvstore.

Drunix

Fabric 2.5 fork. Lite Peer / Committing Peer split. Writes via JSON wrap.

Fabric-X

EOV without chaincode. Native Arma gRPC + Postgres committer.

NeuChain

Ordering-free EV. ZMQ + YCSB. Image exists; setup can still fail.

Core ideas

  • T1 / T2 / T3 — schedule/submit-enter / platform ack / committed. Headlines use T3. NeuChain’s T2 is local send only — not comparable.
  • Probe-and-sweep — floor latency → shared TPS ladder → hold at 90% of the measured knee.
  • Fairness by construction — identical normalized YAML, seed, windows, resource budget; caveats when a lever cannot be held.
  • Manifest every run — versions, crypto, state DB, batch params, git SHA, caveats.

Quick start

# full campaign (recommended)
make bench PROFILE=local-32gb \
  PLATFORMS="fabric-cft fabric-bft drunix fabricx neuchain" \
  CONFIGS=configs/normalized/probe-sweep.yaml

# single platform
bash deploy/docker/fabric-cft/up.sh local-32gb
set -a; source deploy/docker/fabric-cft/connection.env; set +a
./bin/benchrunner run --config configs/normalized/quick-smoke.yaml \
  --platform fabric-cft --profile local-32gb
bash deploy/docker/fabric-cft/down.sh
