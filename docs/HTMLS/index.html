Unified Blockchain Benchmark Harness Fair, platform-agnostic throughput/latency benchmarking across four permissioned blockchains built on three different transaction models

One adapter interface, one load generator, one metrics pipeline drive every platform below. Normalized workloads make the cross-platform comparison possible; each platform's own native workload separately shows its ceiling. Every methodology decision behind these numbers is written up on its own page — start with whichever platform you care about, or read how the four are made comparable first if you want the full picture before the details.

The platforms

Hyperledger Fabric

Execute-Order-Validate + chaincode. Raft (CFT) or SmartBFT (BFT) ordering.

Drunix

NPCI's fork of Fabric 2.5.x. Same EOV model, disaggregated peer, Raft only.

Fabric-X

EOV without chaincode — UTXO/Token-SDK model, Arma sharded BFT ordering.

NeuChain

Ordering-free Execute-Validate. Agreement via deterministic execution, no orderer.

Core ideas that apply to every platform

  • T1 / T2 / T3 — submit-entered / platform-acknowledged / committed-in-block. Throughput and headline latency always use T3. Full explanation, and why T2 doesn't mean the same thing on all four platforms, is on the normalization page.
  • Probe-and-sweep — find floor latency, step load up to saturation, then hold at 90% of the detected knee to measure stability.
  • Fairness by construction — identical configuration (state DB, orderer batch params, workload, seed) for every normalized run; each platform's own native metrics are recorded but never used in a cross-platform comparison table.
  • Every run writes a manifest capturing every fairness lever, every version, the git SHA, and any caveats — so two runs that disagree can always be explained.

Quick start

./bin/benchrunner run --config configs/quick-smoke.yaml --platform mock   # no network needed

./bin/benchrunner setup --platform fabric-cft --profile local
set -a; source deploy/docker/fabric-cft/connection.env; set +a

./bin/benchrunner teardown --platform fabric-cft
