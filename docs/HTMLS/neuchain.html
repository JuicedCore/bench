1. What it is

NeuChain (VLDB / ev branch) agrees by deterministic execution — there is no separate ordering service. Clients publish transactions; nodes execute and validate. That removes Fabric’s endorse→order split and changes what T2 can mean.

2. How we measure it

  • Submit — YCSB update protobuf, RSA-1024 sign, ZMQ PUB to block servers 5001 / 5011 / 5021 / 5031.
  • T2 — local send return (fire-and-forget). Not a platform ack. Do not compare submit latency to Fabric / Fabric-X.
  • Finality — poll tip/block on 7003+ until the tx appears → T3.
TxWrite → YCSB update + RSA → ZMQ PUB :5001(+10n) T2 = send returned → deterministic EV on block servers → REQ poll :7003(+10n) → T3
Comparable metrics

Use confirmed TPS and e2e (T3) only. NeuChain has no orderer_batch lever. Crypto is RSA-1024 without per-tx endorsement verify — disclosed in the manifest.
